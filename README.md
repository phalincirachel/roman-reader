# Roman-Reader

Lese- und Schreiboberfläche für einen Roman, der in einem Zettelkasten (.zkn3) liegt.

Die Seite enthält keine Daten. Sie lädt den Text mit einem persönlichen Zugangsschlüssel
direkt aus einem privaten GitHub-Repository und legt Änderungen dort ab; der Schlüssel
bleibt im Browser. Der Code wird aus einem privaten Projekt hierher kopiert.

Enthalten ist [marked](https://github.com/markedjs/marked) (MIT-Lizenz, siehe
`static/vendor/marked-LICENSE.md`).
